Examination Overview

The Visvesvaraya Technological University Eligibility Test for Research (VTU-ETR) qualifies candidates for admission into Ph.D. and M.S. (Research) degrees.

Key Exam Structure

Parameter Details
Total Marks 100 Marks
Total Questions 100 Multiple Choice Questions (MCQs)
Duration 3 Hours (180 Minutes)
Marking Scheme 1 Mark per Question | NO Negative Marking
Part A 50% (50 MCQs) - Research Methodology
Part B 50% (50 MCQs) - Computer Science & Engg / Information Science

High-Yield Repeated Questions

1. Research Methodology: Type-I Error

Question: Type-I error occurs if:

Answer: Null Hypothesis is rejected even if it is true

2. Data Structures: BST Node Count

Question: BST inserting order: 50, 15, 62, 5, 20, 58, 91, 3, 8, 37, 60, 24. Left & Right subtrees node count:

Answer: (7, 4)

3. Operating Systems: Thrashing

Question: Thrashing occurs when:

Answer: Processes spend more time paging than executing

4. Computer Networks: Presentation Layer

Question: Which OSI layer is responsible for data presentation/formatting?

Answer: Presentation Layer

Computer Science & Information Science (50%)

Unit 1: Data Structures and Applications

Arrays, strings, stacks, recursion, queues, linked lists, trees, sorting and searching.

Unit 2: Discrete Mathematical Structures

Logic, Integer properties, principles of counting, relations, functions, graph theory.

Unit 3: Software Engineering

Requirements engineering, RUP, UML, software testing, project planning, agile development.

Unit 4: Computer Organization

Machine instructions, I/O organization, memory hierarchy, computer arithmetic, basic processing unit.

Unit 5: Design and Analysis of Algorithms

Asymptotic notation, Divide & Conquer, Greedy, Dynamic Programming, Backtracking.

Unit 6: Operating Systems

Multithreading, Deadlocks, Virtual memory, Paging, Secondary storage, Protection.

Unit 7: Computer Networks

Digital transmission, MAC, Ethernet, Application layer, Transport layer, Network layer, Security.

Unit 8: Object-Oriented Modeling & Design

Use cases, System design, Class diagrams, Sequence diagrams, Design Patterns (e.g. Observer, Adapter).

Unit 9: Database Management Systems

Relational model, Relational Algebra, SQL, Normalization (1NF to BCNF), Transactions, External sorting.

Unit 10: System Modeling & Simulation

Queuing models, Random number generation, Input modeling, Verification, Calibration, Validation.

Research Methodology (50%)

UNIT 1: Introduction & Research Problem

Types of research, Scientific Method, Research Process, Defining the Problem.

UNIT 2: Literature Review & Research Design

Theoretical & Conceptual Frameworks, Experimental Designs, Principles of Design.

UNIT 3: Sampling, Measurement & Data Collection

Probability vs Non-probability sampling, Measurement Scales, Primary & Secondary Data.

UNIT 4: Data Preparation & Descriptive Statistics

Editing, Coding, Missing Values, Central Tendency, Dispersion, Skewness, Kurtosis.

UNIT 5: Statistical Inference & Central Limit Theorem

Parameters, Statistics, Standard Error, Sampling Distributions, Central Limit Theorem.

UNIT 6: Hypothesis Testing & Chi-Square

Null & Alternative Hypotheses, Critical Region, P-Value, Power of Test, Chi-Square Goodness of Fit.

UNIT 7: Analysis of Variance (ANOVA)

One-way & Two-way ANOVA, F-ratio, Latin Square Design, ANCOVA.

UNIT 8: Regression & Factor Analysis

Simple & Multiple Linear Regression, Multicollinearity, Factor Analysis (R-Type & Q-Type).

UNIT 9: Probability & Random Variables

Probability Axioms, Conditional Probability, Bayes' Theorem, Discrete & Continuous Random Variables.

UNIT 10: Probability Distributions

Binomial, Normal (Gaussian), Poisson, and Hypergeometric Distributions.
