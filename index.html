Examination Overview

The Visvesvaraya Technological University Eligibility Test for Research (VTU-ETR) qualifies candidates for admission into Ph.D. and M.S. (Research) degrees.

Key Exam Structure

Parameter Details
Total Marks 100 Marks
Total Questions 100 Multiple Choice Questions (MCQs)
Duration 3 Hours (180 Minutes)
Marking Scheme 1 Mark per Question | NO Negative Marking
Part A 50% (50 MCQs) - Research Methodology
Part B 50% (50 MCQs) - Computer Science & Engg / Information Science

High-Yield Repeated Questions

1. Research Methodology: Type-I Error

Question: Type-I error occurs when:

Answer: Null Hypothesis is rejected even if it is true ($H_0$ is true)

2. Data Structures: BST Node Count

Question: BST insertion order: 50, 15, 62, 5, 20, 58, 91, 3, 8, 37, 60, 24. Left & Right subtrees node count:

Answer: (7, 4)

3. Operating Systems: Thrashing

Question: Thrashing in OS memory management occurs when:

Answer: Processes spend more time page swapping/paging than executing code

4. Computer Networks: Presentation Layer

Question: Which OSI layer handles data compression, encryption, and formatting?

Answer: Presentation Layer (Layer 6)

5. Research Methodology: Type-II Error

Question: Type-II error ($\beta$) occurs when:

Answer: Failing to reject (accepting) a false Null Hypothesis ($H_0$ is false)

6. Database Systems: Normalization

Question: A relation table is in 3NF if it is in 2NF and has no:

Answer: Transitive Dependencies

7. Design & Analysis of Algorithms: Dijkstra's Algorithm

Question: Dijkstra's Single Source Shortest Path fails when graph edges have:

Answer: Negative weights or negative cycles

8. Software Engineering: Coupling vs Cohesion

Question: In good software modular architecture, software modules should have:

Answer: High Cohesion and Low Coupling

9. Research Methodology: Sampling Technique

Question: Snowball sampling is categorized under which type of sampling method?

Answer: Non-Probability Sampling

10. Computer Organization: Cache Memory Alignment

Question: Principle of locality of reference is used to justify the presence of:

Answer: Cache Memory

11. Intellectual Property Rights: Patent Duration

Question: What is the standard term duration of a granted Patent in India from filing date?

Answer: 20 Years

12. Discrete Mathematics: Handshaking Lemma

Question: In an undirected graph, the sum of degrees of all vertices equals:

Answer: Twice the total number of edges ($2 \times |E|$)

Computer Science & Information Science (50%)

CS/IS Syllabus Completion 0 of 10 Units Completed (0%)
Unit 1: Data Structures and Applications
►

Detailed Topics: Introductions, primitive, arrays, strings, stacks recursion, queues, linked lists, trees, sorting and searching.

📖 Reference Books:
  1. Ellis Horowitz and Sartaj Sahni, Fundamentals of Data Structures in C, Universities Press.
  2. Seymour Lipschutz, Data Structures Schaum's Outlines, McGraw Hill.
Unit 2: Discrete Mathematical Structures
►

Detailed Topics: Fundamentals of logics, properties of Integers, principles of counting, relations and functions, inclusion and exclusion, graph theory.

📖 Reference Book: Ralph P. Grimaldi: Discrete and Combinatorial Mathematics, Pearson Education.
Unit 3: Software Engineering
►

Detailed Topics: Introduction, requirement engineering, RUP, UML, software testing, project planning, agile software development.

📖 Reference Book: Ian Sommerville: Software Engineering, Pearson Education.
Unit 4: Computer Organization
►

Detailed Topics: Machine instructions and programs, input/output organization, memory, Arithmetic, and basic processing unit.

📖 Reference Book: Carl Hamacher, Zvonko Vranesic, Safwat Zaky: Computer Organization, 5th Edition, Tata McGraw Hill, 2002.
Unit 5: Design and Analysis of Algorithms
►

Detailed Topics: Introduction to algorithms, performance, divide and conquer, greedy, dynamic programming, backtracking.

📖 Reference Books:
  1. Anany Levitin, Introduction to the Design and Analysis of Algorithms, Pearson.
  2. Ellis Horowitz, Sartaj Sahni and Rajasekaran, Computer Algorithms / C++, Universities Press.
Unit 6: Operating Systems
►

Detailed Topics: Introduction, multi-threaded programming, Deadlocks, virtual memory management, secondary storage structures and protections.

📖 Reference Book: Abraham Silberschatz, Peter Baer Galvin, Greg Gagne: Operating System Principles, Wiley-India.
Unit 7: Computer Networks
►

Detailed Topics: Introduction, Digital transmission, bandwidth utilization, Data link control, media access control, wired LAN and Ethernet. Application layer, Transport layer, Network layer, Network security.

📖 Reference Books:
  1. Behrouz A. Forouzan, Data Communications and Networking.
  2. James F Kurose and Keith W Ross, Computer Networking, A Top-Down Approach, Sixth edition, Pearson.
Unit 8: Object-Oriented Modeling & Design
►

Detailed Topics: Use cases, System design, Class diagrams, Sequence diagrams, Design Patterns (Observer, Adapter, Factory, Singleton).

📖 Reference Book: Michael Blaha, James Rumbaugh: Object-Oriented Modeling and Design with UML, Pearson.
Unit 9: Database Management Systems
►

Detailed Topics: Relational model, Relational Algebra, SQL queries, Normalization (1NF to BCNF), Transaction processing, Concurrency control, External sorting.

📖 Reference Book: Ramez Elmasri, Shamkant B. Navathe: Fundamentals of Database Systems, Pearson.
Unit 10: System Modeling & Simulation
►

Detailed Topics: Queuing models, Random number generation, Input modeling, Verification, Calibration, Validation, Simulation software tools.

📖 Reference Book: Jerry Banks, John S. Carson II, Barry L. Nelson: Discrete-Event System Simulation, Pearson.

Research Methodology (50%)

RM Syllabus Completion 0 of 10 Units Completed (0%)
UNIT 1: Introduction & Research Problem
►

Detailed Topics: Meaning, objectives, and motivation of research; Types of research (Descriptive vs Analytical, Applied vs Fundamental); Research process, defining the research problem, literature review, citation networks, research ethics.

📖 Reference Book: C.R. Kothari & Gaurav Garg, Research Methodology: Methods and Techniques, New Age International.
UNIT 2: Literature Review & Research Design
►

Detailed Topics: Theoretical & conceptual frameworks, experimental designs, randomized block designs, principles of experimental design, literature search strategies.

📖 Reference Book: John W. Creswell, Research Design: Qualitative, Quantitative, and Mixed Methods Approaches, SAGE.
UNIT 3: Sampling, Measurement & Data Collection
►

Detailed Topics: Probability vs Non-probability sampling, sample size determination, measurement scales (Nominal, Ordinal, Interval, Ratio), sources of errors, questionnaires, primary & secondary data collection.

📖 Reference Book: Donald R. Cooper & Pamela S. Schindler, Business Research Methods, McGraw Hill.
UNIT 4: Data Preparation & Descriptive Statistics
►

Detailed Topics: Editing, coding, classification, missing values treatment, measures of central tendency, dispersion, skewness, kurtosis, data visualization tools.

📖 Reference Book: Richard I. Levin & David S. Rubin, Statistics for Management, Pearson.
UNIT 5: Statistical Inference & Central Limit Theorem
►

Detailed Topics: Parameters, sample statistics, standard error, sampling distributions, law of large numbers, Central Limit Theorem applications.

📖 Reference Book: S.P. Gupta, Statistical Methods, Sultan Chand & Sons.
UNIT 6: Hypothesis Testing & Chi-Square
►

Detailed Topics: Null & Alternative hypotheses, Type-I and Type-II errors, critical region, p-value, power of test, z-test, t-test, Chi-Square test for independence & goodness of fit.

📖 Reference Book: C.R. Kothari & Gaurav Garg, Research Methodology: Methods and Techniques, New Age International.
UNIT 7: Analysis of Variance (ANOVA)
►

Detailed Topics: One-way and Two-way ANOVA, F-distribution, variance decomposition, Latin Square Design, ANCOVA concepts.

📖 Reference Book: Douglas C. Montgomery, Design and Analysis of Experiments, Wiley.
UNIT 8: Regression & Factor Analysis
►

Detailed Topics: Simple & Multiple linear regression, coefficient of determination ($R^2$), multicollinearity, factor analysis (R-Type & Q-Type), principal component analysis.

📖 Reference Book: Joseph F. Hair et al., Multivariate Data Analysis, Pearson.
UNIT 9: Intellectual Property Rights & Patents
►

Detailed Topics: Overview of IPR, Patent eligibility criteria (Novelty, Inventive Step, Industrial Applicability), non-patentable subject matter, filing patent applications, patent commercialization.

📖 Reference Book: Prabuddha Ganguli, Intellectual Property Rights: Unleashing the Knowledge Economy, Tata McGraw-Hill.
UNIT 10: Copyrights & Trademarks
►

Detailed Topics: Copyright definitions, classes, exclusive rights of owners, Fair Use doctrine, Trademark registration process, qualifications, and categories under Indian law.

📖 Reference Book: V.K. Ahuja, Law Relating to Intellectual Property Rights, LexisNexis.

Important Examination Guidelines

  • Minimum Qualifying Score: Candidates must score at least 50% aggregate marks in the VTU-ETR entrance exam to qualify for the interview phase.
  • Part A & Part B Balance: The paper is divided equally into 50 MCQs for Research Methodology and 50 MCQs for Computer Science / Information Science.
  • Negative Marking: There is NO negative marking for incorrect answers. Candidates are encouraged to attempt all 100 questions.
  • Interview & Selection: Qualified candidates are called for a pre-registration interview where they present their broad research interest domain before the Ph.D. committee.
